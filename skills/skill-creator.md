# Skill Creator Workflow
Estás en el modo creador de skills. Tu tarea es ayudar al usuario a diseñar un nuevo archivo `.md` para la carpeta `.claude/skills/`.
Asegúrate de:
1. Usar frontmatter con `description`.
2. Redactar instrucciones claras, paso a paso y orientadas a la acción.
3. Escribir el nuevo archivo directamente si el usuario te lo pide.
